# Bundled themes

These btop-compatible palettes are bundled so ltop has a useful dark and light
selection without requiring btop to be installed. They are derived from theme
files distributed by the [btop project](https://github.com/aristocratos/btop),
with original attribution retained in each file.

ltop can also load other btop `.theme` files from its own theme directories or
from an existing btop installation.

These files are embedded into the executable at build time. They can also serve
as examples for custom palettes placed in `~/.config/ltop/themes`; ltop uses the
same `theme[role]="color"` syntax and three-stop gradients as btop.
